# n8n-sheets-backend

Learning and teaching backend workflows using n8n and Google Sheets.

---

## 🎯 Mục tiêu của repo

Repo này được xây dựng nhằm:

- Học **n8n** theo hướng *backend workflow*, không chỉ automation rời rạc
- Sử dụng **Google Sheets** như database khởi đầu (dễ sống, dễ triển khai)
- Chuẩn bị nền tư duy để mở rộng sang:
  - Supabase / Database thật
  - Backend viết tay (Go)
  - Tích hợp AI (LLM, chatbot, trợ lý học tập)

Trọng tâm: **sống được trước – mạnh sau**.
